# Japan Reiseplaner 3

Neu: Startseite (Countdown, nächster Tag), Buchungs-Checkliste, Reiseunterlage zum Drucken oder Speichern (offline).
Öffnen: https://lukiwarth.github.io/japan-planerv3/ (GitHub Pages: Settings > Pages > Branch main, Ordner / root).
Beim ersten Start werden vorhandene Pläne aus Version 2 übernommen.

## Neu in dieser Version
- **Tag-Ansicht**: ein Tag pro Seite mit Tagesleiste, Zeitachse und Karte, die der Tagesroute folgt; Umschalter auf Monat und alle Tage.
- **Kartenfilter** (🔍): Orte nach Typ ausblenden, nur Orte des gewählten Tages zeigen.
- **Fotos**: Karten-Ansicht mit Titelbild für Orte, Impressionen-Raster pro Ziel.
- **Variantenvergleich**: Tage, Kosten, Strecke, Blüte-Treffer und Schwerpunkte aller fünf Varianten nebeneinander.
- **Gemeinsam planen**: Plan über jsonblob.com teilen (Link `#j=…`), automatischer Abgleich; Fotos bleiben lokal.
